# mullvad_checker

Проверка аккаунтов Mullvad через официальный API. Один файл Go, без внешних зависимостей.

## Что делает

Для каждого номера:

1. `POST https://api.mullvad.net/auth/v1/token` с `{"account_number":"..."}`
   - `200` — номер существует, возвращается access token
   - `400 {"code":"INVALID_ACCOUNT"}` — номера нет
2. `GET https://api.mullvad.net/accounts/v1/accounts/me` с `Authorization: Bearer <token>`
   - возвращает `expiry`, `max_devices`, `max_ports`, `has_payments`

Классы результата: `active` (время вперёд), `expired` (существует, срок вышел), `invalid` (номера нет), `err` (429 / сеть — перепроверяется следующим проходом).

## Сборка

Нужен Go 1.21+.

```
go build -ldflags "-s -w" -o mullvad_checker mullvad_checker.go
```

Готовые бинарники лежат в этой же папке, Go на машине получателя не нужен.

## Запуск

```
mullvad_checker -i accounts.txt -o valid.txt -p proxies.txt -w 40 -t 15s -r 3 -passes 3
```

Флаги:

| флаг | по умолчанию | что делает |
|---|---|---|
| `-i` | accounts.txt | входной файл, один номер в строке |
| `-o` | valid.txt | выходной файл |
| `-p` | — | список прокси |
| `-w` | 50 | число воркеров |
| `-r` | 2 | повторы на ошибку / 429 |
| `-t` | 20s | таймаут запроса |
| `-passes` | 2 | проходы; повторные перепроверяют только ошибочные |
| `-dfail` | 3 | промахов подряд до отключения прокси |
| `-active` | — | писать только непросроченные |
| `-any` | — | принимать любой токен, не только 16 цифр |
| `-v` | — | печатать каждый результат |
| `-direct` | — | разрешить работу без прокси на своём IP |
| `-pcheck` | — | только проверить прокси и записать живые в `-o` |
| `-probe` | api-addrs | URL для `-pcheck` |

## Формат файлов

Аккаунты — один номер в строке. Строки с `#`, пустые, дубликаты и всё, что не 16 цифр, отбрасываются; счётчик отброшенных печатается при старте. Дампы вида `url:login:pass` тоже разбираются — номер берётся из любой позиции.

Прокси — по одному в строке:

```
socks5://user:pass@1.2.3.4:1080
http://1.2.3.4:8080
user:pass@1.2.3.4:49155      # без схемы — считается socks5
```

## Порядок работы с новым пулом прокси

Сначала отфильтровать мёртвые, иначе таймауты съедят всё время:

```
mullvad_checker -pcheck -p proxies.txt -o proxies_live.txt -w 80 -t 5s
```

Потом проверка аккаунтов через `proxies_live.txt`.

## Выход

`-o` в формате TSV:

```
8207944601142539	status=active	expiry=2026-11-26T04:40:39Z	days=28	max_devices=5	payments=true	ports=0
```

В конце печатается сводка и транспортная строка — сколько разных прокси реально работало и сколько запросов ушло напрямую. Если там `0 requests direct`, весь трафик прошёл через прокси.

## Защита от своих же ошибок

Без `-p` на больше чем один аккаунт программа отказывается работать (код выхода 2) — один запрос с личного IP это проверка, тысяча это троттлинг. Разрешается явным `-direct`.

## Заметки

- `/www/accounts/{n}` — старый маршрут, в 2026-м отдаёт `{"code":"NOT_FOUND"}` на любой ввод, включая валидные номера. Не использовать.
- 429 от API — троттлинг, не бан. Снимается за минуты, лечится количеством прокси и `-r`.
- Windows Defender может ругаться на собранный `.exe` из-за эвристики на «checker»-бинарники. Раздавать исходник `.go` надёжнее — он собирается одной командой.
